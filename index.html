Security controls

The page is intentionally small so each defensive decision stays visible and auditable.

CSP

Restrictive policy

Blocks object embeds, framing, non-self scripts, and unsafe form targets at the document level.

DOM

Safe rendering

Untrusted text is inserted with textContent instead of HTML parsing, reducing DOM XSS risk in this demo.

Production notes

This repository is a security-oriented frontend sample, not a guarantee of application security. For production, enforce security headers at the web server/CDN layer and validate every request again on the server.
